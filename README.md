# GDG-QR-Generator
QR code generator is a browser based web application based on react and javascript that enables users to generate a qr code from the url provided by the user . The project uses qrcode.react library to generate QR. It uses Vite as the development environment . the project generates the QR as the URL is entered by the user.  
**what the project does
asks for URL input
generates a QR code for the URL
** technolgies used
react
vite
javascript
qrcode.react library
